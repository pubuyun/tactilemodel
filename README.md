# Tactile Models

Tactile 3D models by **Greatbay-SCIE iGEM Team (2026)**.

## Files and Downloads

- **GLB models:** 20 files in the repository root for viewing in compatible 3D applications.
- **Previews:** 20 PNG images in [`preview/`](preview/), named to match the GLB models.
- **STL models:** all 21 STL files, including an additional DNA Braille variant, are available in the [STL ZIP download for Release 1.0](https://github.com/pubuyun/tactilemodel/releases/download/v1.0/tactilemodel-stl-v1.0.zip).

See the [Release 1.0 page](https://github.com/pubuyun/tactilemodel/releases/tag/v1.0) for release details.
